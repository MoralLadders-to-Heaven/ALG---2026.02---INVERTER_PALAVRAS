# ALG---2026.02---INVERTER_PALAVRAS

O aluno deve desenvolver a lista de exercício em linguagem C utilizando o DEV-C++.

    Crie um repositório PUBLICO no github
    Resolva os exercícios criando um arquivo ".c" para cada exercício. NÃO É PARA FAZER TODOS OS EXERCÍCIOS EM UM ÚNICO ARQUIVO.
    Publique os códigos no seu repositório GitHub
    Preencha o questionário com o link do seu repositório. 

Exercício:

    Criar um programa que leia uma palavra digitada pelo usuário e imprima invertido. Ex: abcd -> dcba
