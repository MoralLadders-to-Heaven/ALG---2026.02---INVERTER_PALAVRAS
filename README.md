## Exercício Desenvolvido

### Inversão de Palavra

Foi desenvolvido um programa que:

- Lê uma palavra digitada pelo usuário
- Armazena o conteúdo em um vetor de `char`
- Percorre a palavra na ordem inversa
- Imprime o resultado invertido na tela

#### Exemplo

```text
Entrada:  abcd
Saída:    dcba
```
